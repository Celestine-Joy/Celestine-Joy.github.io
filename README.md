## ✨ About

This is the source code for my portfolio, live at **[celestine-joy.github.io](https://celestine-joy.github.io/)**.

I'm a computer science engineer studying at **Universidad Carlos III de Madrid (UC3M)**, with industry experience as an Associate Test Engineer at **EY Global Delivery Services**. I'm currently exploring **machine learning and AI**.

## 🚀 Features

- ⌨️ **Typing animation** in the hero section
- 🎞️ **Scroll-reveal animations** as you move down the page
- 📱 **Fully responsive**, with a mobile menu for small screens
- 🌙 **Dark theme** with a purple and teal gradient accent
- 🖼️ **Profile photo synced from GitHub**, falling back to initials if it can't load
- 🔒 **Security-minded**: Content Security Policy, no inline scripts, safe external links
- ♿ **Accessible**: respects `prefers-reduced-motion` and labels icon links
- ⚡ **No frameworks, no build step**: plain HTML, CSS and JavaScript
